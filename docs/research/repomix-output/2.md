## 1. Architecture Verdict

**方向是对的。** 你现在的分层非常接近 Codex-like browser SDK 应该有的形态：LLM 只看到 MCP `node_repl` 的 3 个工具；浏览器能力通过持久 Node kernel 内的 JS SDK 调用；SDK 再走 `agent/browserTools.ts -> native-host -> extension/background.ts -> CDP/content script`。代码包说明也明确把 `mcp-node-repl/browser-client.ts` 定位为第一版 SDK facade，把 `agent/browserTools.ts` 定位为旧 direct browser tool layer/实现细节，而 `native-host/host.ts` 和 `extension/*` 是真实 browser/CDP primitive 承载层。

**不应该把 90+ API 注册成 LLM tools。** 当前 `mcp-node-repl/server.ts` 只注册 `js`、`js_add_node_module_dir`、`js_reset`，README/测试也验证 Codex-like chat 只给模型这三个工具，然后在 JS kernel 里注入 `browser-client.ts`。这条边界应该保持。

**最大的缺失抽象：frame-aware, shadow-aware 的 Locator/TargetContext 层。** 现在后端 action 已经覆盖了很多 tab/session/navigation/input/CDP 能力，`shared/types.ts` 里也已有 `health/getEvents/startSession/claimTab/createTab/openUrl/click/typeText/evaluate/screenshot/cdp/listDownloads/closeTab/finalizeSession/stopSession` 等 action 类型。 但目标 API 的核心不是“多加几十个方法名”，而是把 Playwright-ish `locator`、`frameLocator`、`getByRole`、`expectNavigation` 映射到少量可组合 primitive。这个抽象必须表达：tab、frame chain、selector engine、locator filters、nth/first/last、shadow DOM 策略、重试/等待策略、动作前重新 resolve，而不是保存一次性 element ref。

## 3. Recommended Backend Primitive Set

目标是 **约 25–30 个 backend actions 支撑 90+ JS SDK methods**。不要把每个 SDK method 变成 action。当前已有 action 很多，建议只补缺口，并逐步把旧 action 归一成更稳定 primitive。

| Primitive action                    |                       状态 | 主要用途                                                                  | owner                                                                 |
| ----------------------------------- | -----------------------: | --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `health`                            |                       已有 | extension/native/session/attached tabs 状态                             | `shared/types.ts`, `agent/browserTools.ts`, `extension/background.ts` |
| `getEvents` / `clearEvents`         |                       已有 | buffered navigation/dialog/download/runtime events                    | 同上 + `extension/event-buffer.ts`                                      |
| `waitForEvent`                      |                       新增 | `waitForEvent`, `expectNavigation`, dialog/download/dev events        | `extension/event-buffer.ts`, `extension/background.ts`                |
| `startSession`                      |                       已有 | browser/session 创建                                                    | `extension/session-manager.ts`                                        |
| `nameSession`                       |                       新增 | `browser.nameSession`，tab group title/session metadata                | `extension/session-manager.ts`                                        |
| `claimTab`                          |                       已有 | `browser.user.claimTab`                                               | `extension/session-manager.ts`                                        |
| `listTabs`                          | extension 已有，agent/SDK 缺 | `browser.tabs.list`, `browser.user.openTabs`                          | 补 `agent/browserTools.ts`, `shared/types.ts`, `browser-client.ts`     |
| `getTab`                            |               新增或 facade | `browser.tabs.get`, `tab.title/url`                                   | 可先 facade from `listTabs`，后加 action                                   |
| `createTab`                         |                       已有 | `browser.tabs.new`                                                    | existing                                                              |
| `switchTab` / `selectTab`           |                       已有 | `browser.tabs.selected`, active tab                                   | existing；SDK 可命名 selected/select                                      |
| `closeTab`                          |                       已有 | `tab.close`                                                           | existing                                                              |
| `finalizeSession` / `stopSession`   |                       已有 | `browser.tabs.finalize`, cleanup/handoff                              | existing                                                              |
| `openUrl` / `goto`                  |                       已有 | `tab.goto`                                                            | existing                                                              |
| `goBack` / `goForward`              |                       已有 | tab history                                                           | existing                                                              |
| `reload`                            |                       已有 | reload                                                                | existing                                                              |
| `waitForLoadState`                  |                       已有 | page load wait                                                        | existing                                                              |
| `waitForUrl`                        |                       已有 | URL wait                                                              | existing                                                              |
| `observe`                           |                       已有 | visible text/elements/AX/DOM snapshot options                         | existing                                                              |
| `domSnapshot`                       |               新增或 facade | `playwright.domSnapshot` without huge observe payload                 | `extension/background.ts` via `DOMSnapshot.captureSnapshot`           |
| `accessibilitySnapshot`             |               新增或 facade | `getByRole`, DOM CUA                                                  | `extension/background.ts` via `Accessibility.getFullAXTree`           |
| `evaluate`                          |                       已有 | page JS evaluate, locator query fallback                              | existing                                                              |
| `locatorQuery`                      |                       新增 | `count`, `isVisible`, `innerText`, `getAttribute`, `allTextContents`  | `extension/background.ts`; shared `LocatorIR` types                   |
| `locatorAction`                     |                       新增 | `click`, `dblclick`, `fill`, `check`, `selectOption`, `press`, `type` | `extension/background.ts`; uses CDP input/runtime                     |
| `pointerAction`                     |                  新增/合并现有 | click/double_click/move/drag/wheel by coordinates                     | can wrap existing `click/moveMouse/scroll`; add drag                  |
| `keyboardAction`                    |       新增/extend existing | full keypress chords, not just 8 keys                                 | replace/extend `pressKey`                                             |
| `typeText`                          |                       已有 | text insert/fill fallback                                             | existing                                                              |
| `screenshot`                        |                       已有 | screenshot                                                            | existing                                                              |
| `uploadFile`                        |                       已有 | file input upload; native validates local file path                   | `native-host/host.ts` + `extension/background.ts`                     |
| `listDownloads` / `waitForDownload` |                       已有 | download lifecycle, `downloadMedia` helper                            | existing                                                              |
| `clipboardRead` / `clipboardWrite`  |                       新增 | clipboard APIs                                                        | `extension/background.ts` + content script fallback                   |
| `getDevLogs`                        |                       新增 | `tab.dev.logs`                                                        | `extension/background.ts` + event-buffer                              |
| `capabilities`                      |         新增 or SDK static | `browser.capabilities.*`, `tab.capabilities.*`                        | `browser-client.ts` initially; backend dynamic later                  |
| `cdp`                               |                       已有 | guarded escape hatch                                                  | existing, but capability-gated                                        |

Ownership rule: `mcp-node-repl/browser-client.ts` should own **classes/facade/composition**; `agent/browserTools.ts` should own only typed RPC wrappers and not be externally registered to the LLM; `native-host/host.ts` should remain transport + local validation such as file-path checks; `extension/background.ts` should own action dispatch and call helper managers; `shared/types.ts` and `shared/protocol.md` should be updated for every real primitive.

## 4. Recommended SDK Object Model

下面是 TypeScript-ish sketch，重点是对象边界，不是完整实现。

```ts
type BrowserName = "extension";

class Agent {
  readonly browsers: Browsers;
  constructor(private rpc: BrowserRPC) {
    this.browsers = new Browsers(rpc);
  }
}

class Browsers {
  constructor(private rpc: BrowserRPC) {}

  async get(name: BrowserName = "extension"): Promise<Browser> {
    if (name !== "extension") throw new Error(`Unknown browser: ${name}`);
    return new Browser(this.rpc, { kind: "extension" });
  }

  async list(): Promise<BrowserName[]> {
    return ["extension"];
  }
}

class Browser {
  readonly user: BrowserUserAPI;
  readonly tabs: Tabs;
  readonly capabilities: CapabilitiesAPI;

  constructor(private rpc: BrowserRPC, readonly info: { kind: BrowserName }) {
    this.user = new BrowserUserAPI(rpc, this);
    this.tabs = new Tabs(rpc, this);
    this.capabilities = new CapabilitiesAPI(rpc, { scope: "browser" });
  }

  async nameSession(name: string, opts?: { sessionId?: string }): Promise<void> {
    await this.rpc.action("nameSession", { name, ...opts });
  }
}

class BrowserUserAPI {
  constructor(private rpc: BrowserRPC, private browser: Browser) {}

  async claimTab(opts: { tabId?: number; active?: boolean } = {}): Promise<Tab> {
    const session = await this.rpc.action("claimTab", opts);
    return new Tab(this.rpc, {
      browser: this.browser,
      sessionId: session.sessionId,
      tabId: session.activeTabId
    });
  }

  async openTabs(): Promise<TabInfo[]> {
    return this.rpc.action("listTabs", {});
  }

  async history(opts?: HistoryQuery): Promise<HistoryEntry[]> {
    return this.rpc.action("listHistory", opts ?? {});
  }
}

class Tabs {
  constructor(private rpc: BrowserRPC, private browser: Browser) {}

  async list(opts?: { sessionId?: string }): Promise<Tab[]> {
    const tabs = await this.rpc.action("listTabs", opts ?? {});
    return tabs.map((t) => new Tab(this.rpc, {
      browser: this.browser,
      sessionId: opts?.sessionId ?? null,
      tabId: t.id
    }));
  }

  async get(tabId: number, opts?: { sessionId?: string }): Promise<Tab> {
    return new Tab(this.rpc, {
      browser: this.browser,
      sessionId: opts?.sessionId ?? null,
      tabId
    });
  }

  async new(opts: { url?: string; active?: boolean; sessionId?: string } = {}): Promise<Tab> {
    const result = await this.rpc.action("createTab", opts);
    return new Tab(this.rpc, {
      browser: this.browser,
      sessionId: result.session.sessionId,
      tabId: result.tab.id
    });
  }

  async selected(opts?: { sessionId?: string }): Promise<Tab> {
    const session = await this.rpc.ensureSession(opts);
    return new Tab(this.rpc, {
      browser: this.browser,
      sessionId: session.sessionId,
      tabId: session.activeTabId
    });
  }

  async finalize(opts: { sessionId: string; keepTabIds?: number[]; closeRest?: boolean }) {
    return this.rpc.action("finalizeSession", opts);
  }
}

class Tab {
  readonly cua: CUAAPI;
  readonly dom_cua: DomCUAAPI;
  readonly playwright: PlaywrightAPI;
  readonly clipboard: ClipboardAPI;
  readonly dev: DevAPI;
  readonly capabilities: CapabilitiesAPI;

  constructor(
    private rpc: BrowserRPC,
    readonly target: { browser: Browser; sessionId: string | null; tabId: number }
  ) {
    this.cua = new CUAAPI(rpc, this);
    this.dom_cua = new DomCUAAPI(rpc, this);
    this.playwright = new PlaywrightAPI(rpc, this);
    this.clipboard = new ClipboardAPI(rpc, this);
    this.dev = new DevAPI(rpc, this);
    this.capabilities = new CapabilitiesAPI(rpc, { scope: "tab", tab: this });
  }

  private params(extra: object = {}) {
    return { sessionId: this.target.sessionId, tabId: this.target.tabId, ...extra };
  }

  async goto(url: string, opts?: { timeoutMs?: number }) {
    return this.rpc.action("openUrl", this.params({ url, ...opts }));
  }

  async back(opts?: WaitOpts) {
    return this.rpc.action("goBack", this.params(opts));
  }

  async forward(opts?: WaitOpts) {
    return this.rpc.action("goForward", this.params(opts));
  }

  async reload(opts?: ReloadOpts) {
    return this.rpc.action("reload", this.params(opts));
  }

  async close() {
    return this.rpc.action("closeTab", this.params());
  }

  async screenshot(opts?: ScreenshotOpts) {
    return this.rpc.action("screenshot", this.params(opts));
  }

  async title(): Promise<string> {
    const obs = await this.rpc.action("observe", this.params({ maxTextLength: 0 }));
    return obs.title;
  }

  async url(): Promise<string> {
    const obs = await this.rpc.action("observe", this.params({ maxTextLength: 0 }));
    return obs.url;
  }
}

class CUAAPI {
  constructor(private rpc: BrowserRPC, private tab: Tab) {}

  click(point: Point | RefTarget | SelectorTarget, opts?: ClickOpts) {
    return this.rpc.action("click", this.tabParams({ ...normalizeTarget(point), ...opts }));
  }

  double_click(target: Point | RefTarget | SelectorTarget, opts?: ClickOpts) {
    return this.click(target, { ...opts, clickCount: 2 });
  }

  move(point: Point, opts?: { waitMs?: number }) {
    return this.rpc.action("moveMouse", this.tabParams({ ...point, ...opts }));
  }

  drag(from: Point, to: Point, opts?: DragOpts) {
    return this.rpc.action("pointerAction", this.tabParams({ type: "drag", from, to, ...opts }));
  }

  scroll(delta: { deltaX?: number; deltaY?: number; x?: number; y?: number }) {
    return this.rpc.action("scroll", this.tabParams(delta));
  }

  type(text: string, opts?: TypeOpts) {
    return this.rpc.action("typeText", this.tabParams({ text, ...opts }));
  }

  keypress(key: string, opts?: KeyOpts) {
    return this.rpc.action("keyboardAction", this.tabParams({ key, ...opts }));
  }

  private tabParams(extra: object) {
    return { sessionId: this.tab.target.sessionId, tabId: this.tab.target.tabId, ...extra };
  }
}

class DomCUAAPI {
  constructor(private rpc: BrowserRPC, private tab: Tab) {}

  async get_visible_dom(opts?: { includeAccessibility?: boolean }) {
    return this.rpc.action("observe", this.params(opts));
  }

  click(selectorOrLocator: string | PlaywrightLocator, opts?: ClickOpts) {
    return this.asLocator(selectorOrLocator).click(opts);
  }

  double_click(selectorOrLocator: string | PlaywrightLocator, opts?: ClickOpts) {
    return this.asLocator(selectorOrLocator).dblclick(opts);
  }

  type(selectorOrLocator: string | PlaywrightLocator, text: string, opts?: TypeOpts) {
    return this.asLocator(selectorOrLocator).type(text, opts);
  }

  keypress(key: string, opts?: KeyOpts) {
    return this.rpc.action("keyboardAction", this.params({ key, ...opts }));
  }

  scroll(delta: ScrollOpts) {
    return this.rpc.action("scroll", this.params(delta));
  }

  private asLocator(value: string | PlaywrightLocator): PlaywrightLocator {
    return typeof value === "string"
      ? new PlaywrightLocator(this.rpc, this.tab, LocatorIR.css(value))
      : value;
  }

  private params(extra: object = {}) {
    return { sessionId: this.tab.target.sessionId, tabId: this.tab.target.tabId, ...extra };
  }
}

class PlaywrightAPI {
  constructor(private rpc: BrowserRPC, private tab: Tab) {}

  evaluate<T>(script: string | Function, arg?: unknown): Promise<T> {
    return this.rpc.action("evaluate", this.params({
      script: serializeEvaluate(script, arg),
      awaitPromise: true
    })).then((r) => r.value as T);
  }

  domSnapshot(opts?: DomSnapshotOpts) {
    return this.rpc.action("domSnapshot", this.params(opts));
  }

  locator(selector: string, opts?: LocatorOptions) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.css(selector, opts));
  }

  getByText(text: string | RegExp, opts?: TextLocatorOpts) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.text(text, opts));
  }

  getByRole(role: string, opts?: RoleLocatorOpts) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.role(role, opts));
  }

  getByLabel(text: string | RegExp, opts?: TextLocatorOpts) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.label(text, opts));
  }

  getByPlaceholder(text: string | RegExp, opts?: TextLocatorOpts) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.placeholder(text, opts));
  }

  getByTestId(id: string | RegExp) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.testId(id));
  }

  frameLocator(selector: string) {
    return new PlaywrightFrameLocator(this.rpc, this.tab, LocatorIR.frame(selector));
  }

  waitForLoadState(state: "load" | "domcontentloaded" = "load", opts?: WaitOpts) {
    return this.rpc.action("waitForLoadState", this.params({ state, ...opts }));
  }

  waitForURL(url: string | RegExp | ((url: string) => boolean), opts?: WaitOpts) {
    return this.rpc.action("waitForUrl", this.params(normalizeUrlMatcher(url, opts)));
  }

  waitForTimeout(ms: number) {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }

  waitForEvent(name: string, opts?: WaitEventOpts) {
    return this.rpc.action("waitForEvent", this.params({ name, ...opts }));
  }

  async expectNavigation<T>(action: () => Promise<T>, opts?: NavigationExpectation): Promise<T> {
    const before = await this.rpc.action("getEvents", this.params({ limit: 1 }));
    const p = action();
    await this.rpc.action("waitForEvent", this.params({
      name: "navigation",
      sinceSequence: before.events.at(-1)?.sequence,
      ...opts
    }));
    return p;
  }

  private params(extra: object = {}) {
    return { sessionId: this.tab.target.sessionId, tabId: this.tab.target.tabId, ...extra };
  }
}

class PlaywrightLocator {
  constructor(
    private rpc: BrowserRPC,
    private tab: Tab,
    readonly ir: LocatorIR
  ) {}

  locator(selector: string) {
    return new PlaywrightLocator(this.rpc, this.tab, this.ir.descendant(LocatorIR.css(selector)));
  }

  getByText(text: string | RegExp, opts?: TextLocatorOpts) {
    return this.locatorIR(LocatorIR.text(text, opts));
  }

  first() { return new PlaywrightLocator(this.rpc, this.tab, this.ir.nth(0)); }
  last() { return new PlaywrightLocator(this.rpc, this.tab, this.ir.last()); }
  nth(index: number) { return new PlaywrightLocator(this.rpc, this.tab, this.ir.nth(index)); }

  filter(opts: LocatorFilter) {
    return new PlaywrightLocator(this.rpc, this.tab, this.ir.filter(opts));
  }

  and(other: PlaywrightLocator) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.and(this.ir, other.ir));
  }

  or(other: PlaywrightLocator) {
    return new PlaywrightLocator(this.rpc, this.tab, LocatorIR.or(this.ir, other.ir));
  }

  all(): Promise<PlaywrightLocator[]> {
    return this.query("all").then((r) =>
      r.matches.map((m: LocatorMatch, i: number) =>
        new PlaywrightLocator(this.rpc, this.tab, this.ir.nth(i))
      )
    );
  }

  count(): Promise<number> { return this.query("count").then((r) => r.count); }
  isVisible(): Promise<boolean> { return this.query("isVisible").then((r) => r.visible); }
  isEnabled(): Promise<boolean> { return this.query("isEnabled").then((r) => r.enabled); }
  textContent(): Promise<string | null> { return this.query("textContent").then((r) => r.value); }
  innerText(): Promise<string> { return this.query("innerText").then((r) => r.value); }
  allTextContents(): Promise<string[]> { return this.query("allTextContents").then((r) => r.values); }
  getAttribute(name: string): Promise<string | null> {
    return this.query("getAttribute", { name }).then((r) => r.value);
  }

  click(opts?: ClickOpts) { return this.action("click", opts); }
  dblclick(opts?: ClickOpts) { return this.action("click", { ...opts, clickCount: 2 }); }
  fill(value: string, opts?: FillOpts) { return this.action("fill", { value, ...opts }); }
  type(text: string, opts?: TypeOpts) { return this.action("type", { text, ...opts }); }
```

## 5. What To Implement First: Staged Plan

### Stage 1: object model + core tab/nav/action

Commit-sized steps:

1. **Introduce class-based SDK beside existing flat client.** Keep current `browser.openUrl()` aliases for compatibility, but make `agent.browsers.get("extension")` return `Browser`.
2. **Add `Tab` identity and state propagation.** Reuse current browser-client state logic: current code already stores remembered `sessionId/tabId` from envelopes and result payloads.
3. **Expose `browser.tabs.new/list/get/selected/finalize`.** Add missing `browser_list_tabs` wrapper/schema for existing backend `listTabs`; optionally add `getTab`.
4. **Expose `tab.goto/back/forward/reload/close/title/url/screenshot`.**
5. **Expose `tab.cua.click/double_click/move/scroll/type/keypress`.** `double_click` maps to `clickCount: 2`; `drag` can be stubbed as unsupported until `pointerAction`.
6. **Add smoke tests that verify only MCP tools are exposed.** Existing smoke test already asserts `["js", "js_add_node_module_dir", "js_reset"]`; extend it to assert object model methods exist.

### Stage 2: locator facade

1. Add `LocatorIR` type in `mcp-node-repl/browser-client.ts` or `shared/locator.ts`.
2. Implement CSS-only `PlaywrightLocator` with facade mappings:

   * `locator.click()` -> `browser_click({ selector })`
   * `locator.fill()` -> `browser_type_text({ selector, text, clear:true })`
   * `locator.press()` -> focus locator then `keyboardAction/pressKey`
   * `count/isVisible/textContent/innerText/getAttribute/allTextContents` -> `evaluate` with safe generated JS.
3. Add `locatorQuery` and `locatorAction` backend only after the facade shape stabilizes.
4. Implement `getByText/getByPlaceholder/getByTestId` as LocatorIR engines, initially evaluated in page JS.
5. Implement `first/last/nth/filter/and/or` as IR transformations, not immediate queries.
6. Make locator operations re-resolve every time; do not cache element refs.

### Stage 3: DOM CUA + accessibility/DOMSnapshot

1. Split `observe` into smaller backend helpers: `getVisibleDom`, `domSnapshot`, `accessibilitySnapshot`.
2. Implement `getByRole` using accessible-name logic. For MVP, DOM heuristic is acceptable; stable version should use AX tree.
3. Add `frameLocator` support:

   * `Page.getFrameTree`
   * frameId -> execution context mapping
   * coordinates translated to top-level viewport for input.
4. Add shadow DOM traversal policy:

   * CSS engine can optionally pierce open shadow roots.
   * Closed shadow roots remain unsupported except through accessibility/CDP where possible.
5. Add locator test fixture with nested iframe + open shadow root + dynamic DOM replacement.

### Stage 4: clipboard/dev logs/capabilities

1. Add `clipboardReadText/writeText`; keep binary clipboard later.
2. Add `getDevLogs` backed by `Runtime.consoleAPICalled`, `Log.entryAdded`, and current exception event buffering. Current event code already buffers selected CDP page/runtime events; extend that rather than adding a separate channel.
3. Add static capabilities registry in SDK:

   * `cua.click`, `cua.drag`, `locator.css`, `locator.role`, `frameLocator`, `clipboard`, `dev.logs`, `rawCdp`.
4. Add backend dynamic capability report from extension `health`.
5. Gate raw `cdp` behind `capabilities.rawCdp` and a clearly named escape hatch.

### Stage 5: UX/safety polish

1. Add explicit user-tab ownership state for `claimTab`.
2. Add visual indicator/session naming for claimed tabs.
3. Add redaction and trust wrappers for all page-derived content.
4. Add better errors for unsupported frames/shadow roots/clipboard permissions.
5. Persist session/event state enough to survive MV3 service worker sleep/reconnect.
6. Document “page content is untrusted” and “raw CDP/evaluate are trusted local escape hatches.” The protocol already states the MVP rules: http/https-only navigation, no `chrome://`/`file://`, raw CDP is trusted local tooling, page-returned values are untrusted, password values are redacted, and observations must be wrapped as untrusted web content.

## 6. Locator Method Mapping

| SDK method                         | Stage 1/2 mapping                                                         | Stable mapping                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `locator.count()`                  | `evaluate`: resolve IR in page, return `.length`                          | `locatorQuery({ kind:"count", locator })`                                          |
| `locator.isVisible()`              | `evaluate`: first match + computed style + rect                           | `locatorQuery({ kind:"isVisible" })`, frame-aware                                  |
| `locator.textContent()`            | `evaluate`: first match `.textContent`                                    | `locatorQuery({ kind:"textContent" })`                                             |
| `locator.innerText()`              | `evaluate`: first visible match `.innerText`                              | `locatorQuery({ kind:"innerText" })`                                               |
| `locator.allTextContents()`        | `evaluate`: all matches map textContent                                   | `locatorQuery({ kind:"allTextContents" })`                                         |
| `locator.getAttribute(name)`       | `evaluate`: first match `.getAttribute(name)`                             | `locatorQuery({ kind:"getAttribute", args:{ name } })`                             |
| `locator.click()`                  | CSS-only: `click({ selector })`; other engines: query rect then CDP click | `locatorAction({ kind:"click" })`, re-resolve + scroll + hit-test                  |
| `locator.dblclick()`               | `click({ selector, clickCount:2 })`                                       | `locatorAction({ kind:"click", clickCount:2 })`                                    |
| `locator.fill(value)`              | CSS-only: `typeText({ selector, text:value, clear:true })`                | `locatorAction({ kind:"fill", value })` with input/contenteditable/select handling |
| `locator.type(text)`               | focus + `Input.insertText` via existing `typeText`                        | `locatorAction({ kind:"type", text })`                                             |
| `locator.press(key)`               | focus + `pressKey/keyboardAction`                                         | `locatorAction({ kind:"press", key })`                                             |
| `locator.check/uncheck/setChecked` | `evaluate` set checked + dispatch events, or click if not checked         | `locatorAction({ kind:"setChecked", checked })`                                    |
| `locator.selectOption`             | `evaluate` select value + input/change events                             | `locatorAction({ kind:"selectOption" })`                                           |
| `locator.waitFor`                  | CSS-only: `waitForSelector`; text: `waitForText`                          | `locatorQuery` polling with state                                                  |
| `locator.first/last/nth`           | IR transform only                                                         | Same                                                                               |
| `locator.filter/and/or`            | IR transform; limited JS evaluator                                        | Same, but backend owns semantics                                                   |
| `getByText`                        | Text engine in JS, normalize whitespace                                   | LocatorIR text engine                                                              |
| `getByRole`                        | Stage 2 approximate implicit roles in DOM                                 | Stage 3 AX-backed accessible role/name                                             |
| `frameLocator`                     | Initially throw clear unsupported error                                   | Frame chain in LocatorIR + execution-context routing                               |
| `expectNavigation`                 | `const p=action(); await waitForUrl/loadState; return p`                  | `waitForEvent("navigation")` using event sequence + lifecycle events               |

Important: current observed element refs are explicitly short-lived in the protocol; refs from `observe()` should be treated as valid only for the latest observation/page state, so the Playwright-like locator layer should be declarative and re-resolve on every action rather than store refs. The current observation model returns page `text` and `elements`, but that content is marked `trust: "untrusted"` in `BrowserObservation`.

## 8. Main Design Traps

**Iframe and cross-origin frame traps.** Current selector/evaluate patterns are top-document centric. Cross-origin frames cannot be queried from parent page JS, and CDP input coordinates must be transformed correctly from frame-local element rects to top-level viewport coordinates. `frameLocator` should not be bolted onto CSS strings; it needs explicit `frameChain` in LocatorIR.

**Shadow DOM traps.** `document.querySelector` does not pierce shadow roots. Open shadow roots can be traversed by injected JS; closed shadow roots generally cannot. Decide early whether locator CSS pierces open shadow roots by default or only through a `pierce` engine.

**Stale locator traps.** Existing `observe()` refs are useful for CUA but are not durable element handles. Playwright-like locators must store query plans, not elements. Every action should re-resolve, scroll into view, verify visibility/enabled state, then act.

**Prompt injection traps.** Page text and DOM snapshots are untrusted web content. Do not let page text generate CDP method names, JS source, local file paths, or system-level instructions. The protocol already marks agent-facing observations as untrusted and warns against passing untrusted page text into raw CDP/evaluate paths.

**User tab claiming traps.** `claimTab` is powerful because it can attach debugger to the user’s active tab. It should require explicit user intent, show a visible session indicator, record ownership, block sensitive schemes, and make finalization/handoff clear.

**Raw CDP escape hatch traps.** Raw CDP is already implemented and useful, but it bypasses much of the safety and API design. Keep it as `tab.dev.cdp` or `browser._unsafe.cdp`, not the primary path. Current debugger manager attaches, enables Page/Runtime/DOM, serializes attach locks, and sends CDP with timeouts; that is good infrastructure, but raw `Runtime.evaluate` remains a trusted-local escape hatch.

**Downloads/uploads/clipboard traps.** Upload currently has native-host validation for absolute local file paths before extension file input handling; keep that pattern. Downloads can reveal local filenames. Clipboard can overwrite user data or read sensitive content. These need explicit capability labels and preferably user-visible affordances.

**Service worker lifecycle traps.** MV3 background service workers can suspend. Your extension already has reconnect alarm/native port handling and in-memory event/session managers, but session/event persistence will matter as the SDK grows. The manifest is MV3 service worker based, and current background registers reconnect/top-level listeners.

## 10. Open Questions

1. **`browser.user.history` scope:** Should it mean Chrome browsing history via `chrome.history`, or only controlled-session tab history? The former needs new permission and stronger privacy UX.
2. **Locator compatibility target:** Do you want Playwright semantics closely enough that users can transfer mental models, or only a Playwright-like ergonomic subset?
3. **Raw CDP exposure location:** Keep `browser.rawCdp` for backward compatibility, but should the new object model hide it under `tab.dev.cdp` or `_unsafe.cdp`?
4. **Frame support MVP boundary:** Should Stage 2 throw on `frameLocator`, or implement same-origin iframe only before cross-origin CDP context routing?
5. **Shadow DOM policy:** Should locators pierce open shadow roots by default?
6. **Clipboard consent:** Is local dev enough to allow direct clipboard read/write, or should write/read require explicit user-visible confirmation?
7. **Session persistence:** Is in-memory session state acceptable through Stage 2, or should session metadata move to `chrome.storage` before locator/dev-log work?
8. **Downloads and local paths:** Should downloaded local filenames be returned to the JS SDK by default, redacted, or gated behind capability/explicit option?
9. **Capability contract:** Should capabilities be static SDK declarations, backend-reported runtime facts, or both with “available/unavailable/reason”?
