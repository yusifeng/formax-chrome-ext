# Rust Native Frame Handoff

You are helping migrate one small, stable protocol utility from TypeScript to Rust in the Formax browser agent project.

## Goal

Implement a Rust equivalent of:

```text
shared/native-frame.ts
```

Do not rewrite the Chrome extension, native host, MCP server, browser client, or skill in this task. This handoff is intentionally scoped to the Chrome Native Messaging frame codec only.

The TypeScript source currently is:

```ts
export function encodeNativeMessage(message: unknown): Buffer {
  const body = Buffer.from(JSON.stringify(message), "utf8");
  const header = Buffer.alloc(4);

  header.writeUInt32LE(body.length, 0);

  return Buffer.concat([header, body]);
}

export function decodeNativeMessages(
  buffer: Buffer
): { messages: unknown[]; remaining: Buffer } {
  const messages: unknown[] = [];
  let remaining = buffer;

  while (remaining.length >= 4) {
    const messageLength = remaining.readUInt32LE(0);

    if (remaining.length < 4 + messageLength) {
      break;
    }

    const body = remaining.subarray(4, 4 + messageLength);
    remaining = remaining.subarray(4 + messageLength);
    messages.push(JSON.parse(body.toString("utf8")));
  }

  return {
    messages,
    remaining
  };
}
```

## Protocol

Chrome Native Messaging frames are:

```text
4-byte unsigned little-endian length
UTF-8 JSON body of exactly that length
```

The decoder must support streaming:

- zero complete frames
- one complete frame
- multiple concatenated frames
- a partial frame left in `remaining`
- a split frame that can be completed by appending later bytes

The Rust behavior should match the TypeScript behavior unless this prompt explicitly asks for a safer improvement.

## Suggested Rust API

Implement APIs like:

```rust
use serde::Serialize;
use serde_json::Value;

pub fn encode_native_message<T: Serialize>(message: &T) -> Result<Vec<u8>, NativeFrameError>;

pub fn decode_native_messages(buffer: &[u8]) -> Result<DecodedNativeMessages, NativeFrameError>;

#[derive(Debug, Clone, PartialEq)]
pub struct DecodedNativeMessages {
    pub messages: Vec<Value>,
    pub remaining: Vec<u8>,
}
```

Suggested error enum:

```rust
#[derive(Debug)]
pub enum NativeFrameError {
    JsonSerialize(serde_json::Error),
    JsonDeserialize(serde_json::Error),
    MessageTooLarge { length: usize },
    FrameLengthOverflow { length: u32 },
}
```

Important: the current TypeScript decoder throws if a complete frame contains invalid JSON. The Rust decoder should return `Err(NativeFrameError::JsonDeserialize(...))`.

## Safety Improvements Allowed

The TypeScript implementation is very small and does not enforce maximum message length. Rust may add a conservative max frame size to avoid memory abuse, but only if it is explicit and tested.

Suggested constant:

```rust
pub const MAX_NATIVE_MESSAGE_BYTES: usize = 64 * 1024 * 1024;
```

Behavior:

- encoding a JSON body larger than max returns `MessageTooLarge`
- decoding a declared frame length larger than max returns `MessageTooLarge`
- incomplete frames under max remain in `remaining`

Do not silently truncate.
